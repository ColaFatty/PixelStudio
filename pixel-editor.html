📖 像素画入门教程

1️⃣ 像素是什么？

像素画（Pixel Art）就是 一格一格 画的画。每一格称为一个「像素」，放大看就是一个个小方块，缩小看就能组成生动的图像——这就是复古游戏的画面风格。

像这样：16×16 的一颗小爱心 ❤️（图标是画出来的示例）

2️⃣ 怎么画线？

选 画笔 🖊️，点一下放一格，按住拖动 连续画线。用 直线工具 📏 点起点、拖到终点松开，画一条笔直的线。

3️⃣ 怎么配色？

右侧是调色板，点任意色块，它就是当前颜色。

  • PICO-8：复古掌机的经典 16 色，像素画圈公认好看
  • GameBoy：4 色灰度，最纯粹的像素味道
  • 想换颜色？用底部 🖌️ 颜色选择器，点 ➕ 加入你的调色板

4️⃣ 明暗与立体感

同一种颜色分 3 层：暗色（阴影）→ 本色（主体）→ 亮色（高光）。比如球体左上亮、右下暗，一下就"鼓"起来了。

5️⃣ 抖动（Dithering）技法

两色交界处画交替的小点（⚪⚫⚪⚫），远处看会"混"出中间色。这是像素画做渐变、做透明感的核心技巧。

黑白点交替 = 看起来是灰色渐变

6️⃣ 小技巧

  • 🖼️ 导入照片或图片，一键变像素画，再改细节
  • ↩️ 撤销Ctrl+Z / ↪️ 重做Ctrl+Y 随便试错
  • 💾 导出PNG 选 4x / 8x，图片更大更清晰
  • 先大轮廓 → 再上色 → 最后明暗，是最顺的画法

7️⃣ 做动画（Phase 2）

画面底部是帧栏：➕ 加帧 / ⧉ 复制当前帧 / 🗑 删帧。每帧画不同动作，点 ▶ 播放，用 🎞️ 导出 GIF 生成动图。

打开「洋葱皮」可看到前后帧半透明叠影，照着上一帧位置画下一帧，动画更连贯（透明度可调）。

8️⃣ 对称绘制（Phase 2）

左栏「对称」开水平镜像，画一笔左右同时出现 —— 画脸、画翅膀神器；四向镜像一下出四个方向。

9️⃣ 选区工具（Phase 3）

左栏选 ✂️ 选区，在画布上拖动框选一个方块；框选后可在框内按住拖动移动整块内容（原位变透明），或点按钮水平翻转 / 垂直翻转 / 旋转 90°。

  • Ctrl+C 复制 → Ctrl+V 粘贴，粘贴的是浮动层，鼠标点哪就贴哪
  • Esc 取消选区

1️⃣0️⃣ 形状工具（Phase 3）

左栏 ⬜ 矩形 或 ⬭ 椭圆：点起点拖到终点松开。默认空心边框，勾选「实心」变填充块。

1️⃣1️⃣ 自动保存

内容会自动保存到浏览器本地，关掉页面再打开，上次画的还在，不怕丢。

🖼️ 导入图片转像素画

图片按比例缩小后居中画到当前画布（透明部分保留）。

🎨 颜色模式

映射调色板 = 成品像素感更强；自定义颜色数 = 更接近原图渐变。

💾 导出 PNG

导出无缩放的纯像素 PNG，放大后边缘依旧清晰。

🎞️ 导出 GIF 动画

将 帧导出为 GIF 动画。

循坏播放根据侧栏「循环播放」开关；关闭则单次播放。
